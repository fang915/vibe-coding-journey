# Day 24｜菜品图「空块」修复记录

> 一句话结论：图片加载不出来这件事，**不是把图救回来**，而是**给页面一条活路** ——
> 图源不可达时显示本地占位图，但数据里的原始地址一个字都不动，留一个开关随时切回去。

---

## 一、现象

列表页第一排 5 张卡、详情页正文上方，都是一块**空的粉色色块**；
控制台每次刷新留有资源加载失败的红字。

## 二、排查：把嫌疑逐个排除

| 嫌疑 | 怎么验的 | 结论 |
| --- | --- | --- |
| 本机断网 | 打开一个公共站点，0.2s 正常 | ❌ 网络是通的 |
| 后端挂了 | 直接调接口，正常返回全部菜品 | ❌ 接口正常 |
| JS 跑了但报错 | 四个视图 × 十几组刁钻输入，运行时异常 0 条 | ❌ 脚本没崩 |
| **图床不可达** | 该域名 SSL 握手一路超时；图片下载实测全失败 | ✅ **真凶** |

## 三、根因

两个原因叠在一起，才有了那块「看着像坏了、又说不清哪坏了」的空块：

1. **图源系统性不可达**：数据里的菜品图指向境外的 Wikimedia Commons，在本网络下拿不到。
2. **代码没有任何兜底**：图片加载失败时，`<img>` 仍然是「有尺寸、没内容」——
   于是露出下面 CSS 写的淡色底，就成了那块粉块。详情页还因为 HTML 上留着
   `width`/`height` 属性，被撑成 629px 高的一整屏空块，图下甚至还署着真图作者的名。

同源的两个小毛病：

- 卡片图原本写成 `<img id="card-image" src="">`，**空 src 会被浏览器解析成「当前页面地址」**
  再发一次请求；
- 页面没有声明站点图标，浏览器按默认规则去要 `/favicon.ico`，服务器没这个文件 → 404。

## 四、修法（三件事，外加一个余力加练）

1. **本地占位图**：新增 `assets/placeholder-dish.svg`（淡底 + 碗筷图标 + 「暂无配图 / Photo coming soon」，660×440 即 3:2）。
2. **失败兜底**：新增 `bindImageFallback()`，真图加载失败时自动切占位图；
   用 `data-fallback` 标记防死循环，切占位图时撤掉 `width`/`height` 属性（那块高粉块就是这么来的）。
3. **图源开关**：`js/app.js` 里 `IMAGE_SOURCE = 'placeholder' | 'remote'` 一个常量切换。
   **`data/` 里的图 URL 一个字没动**，将来图源换成国内可达地址或转存到云存储，改回 `'remote'` 即生效。
4. **余力加练**：补 `assets/favicon.svg` 并在 `index.html` 声明，消掉 favicon 404。

## 六、验证过程中新踩的一个坑（值得记下）

第一版占位图做完，量出来的结果却是「**图还是不显示**」：`naturalWidth` 为 0，详情页图片区塌成 28px。

原因不在 JS，在那个 SVG 文件本身：注释里写了 `--brand-bg` 这类 CSS 变量名，
而 **XML 注释中不允许出现连续两个连字符**。浏览器据此判定这个 SVG 不是合法 XML，整张图拒绝渲染 ——
而且**不报错**，只是静静不显示，很容易被误判成「代码没生效」或「缓存没清」。

- 修法：注释里的变量名只写后半截（`brand-bg`），教训抄进两个 SVG 文件里。
- 自查手段：用 XML 解析器过一遍，比盯着浏览器猜快得多：
  ```bash
  python -c "import xml.etree.ElementTree as ET,sys;ET.parse(sys.argv[1]);print('XML 合法')" assets/placeholder-dish.svg
  ```

**问：图为什么会变成一块空块？你怎么证明修好了？**

答：图床（境外 Wikimedia）在这台机器所在网络下系统性不可达，而代码对「图加载失败」没有任何兜底，
`<img>` 保持「有尺寸、没内容」，露出下面 CSS 的淡色底就成了粉块；详情页还因为 HTML 上残留的
`height` 属性被撑成 629px 高。修好之后我做了同机对照：把 `git HEAD` 那一版和当前工作区分别起在
两个端口上、都清空缓存加载，量出来「发往图床的请求 6 次 → 0 次」、
「列表首排有图的缩略图 0/5 → 5/5」、「详情页图片区 658px 空块 → 623px 正常 3:2」、
「控制台错误 1 条 → 0 条」。数字和截图都在报告图里，可以自己复现。
