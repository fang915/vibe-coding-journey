# 寻味 / Xunwei

> 让在华外国人用中英文读懂**一道中国菜的文化来头**。

**MVP v0.1** · 作者 Amity · 2026-09-22

---

## 这是什么

在中国吃到一道不熟悉的地方菜时，人往往会想知道"这是什么、为什么是这个味道、有什么说法"。

问题在于：

- **官方平台**（非遗名录、古籍数据库）内容权威，但用的是"名录语言""典籍语言"，普通人看不懂、外国读者更看不懂；
- **社交平台**（百科、小红书、点评）好读，但多为个人主观说法，**看不出哪一句有依据**。

**「寻味」要做的就是中间那一层**：把权威资料翻译成看得懂的中英双语文化卡片，并且**每一条都标得清出处**。

本版收录 5 道地方美食，其中 **螺蛳粉**已完成内容核实，其余 4 道标注为「内容整理中」。

## 如何在本机运行

### 需要什么

- 浏览器（Chrome / Edge）
- **Python**（Windows 通常自带 `py` 启动器；本项目在本机实测于 Python 3.15 下运行）

> ⚠️ **请不要直接双击 `index.html` 打开。**
> 浏览器的安全规则禁止网页读取本地文件，直接双击会导致**页面读不到数据**（这是浏览器限制，不是代码坏了）。
> 必须通过下面的「本地服务器」方式打开。

### 三步启动

**第 1 步｜打开终端（PowerShell），进入项目文件夹**

```bash
cd "你的项目文件夹路径"
```

> 路径如果含空格或中文，**必须用双引号包起来**，否则终端会把空格当成两个参数。

**第 2 步｜启动本地服务器（端口 8000）**

```bash
py -m http.server 8000
```

看到这一行就说明启动成功：

```
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

> **这个窗口不要关** —— 它就是服务器，关掉网页就打不开了。

**第 3 步｜在浏览器地址栏输入**

```
http://localhost:8000
```

> **注意**：这个地址是输在**浏览器的地址栏**里，不是输在终端里。

### 常见问题

| 现象 | 原因与处理 |
|---|---|
| `py` 不是内部或外部命令 | 改用 `python -m http.server 8000`；或先安装 Python |
| 提示端口被占用 | 换成别的端口，例如 `py -m http.server 8080`，浏览器地址同步改成 `:8080` |
| `http://localhost:8000` 打不开 | 先确认终端窗口还开着（服务器在跑）；也可以试 `http://127.0.0.1:8000` |
| 页面显示"数据没能读出来" | 说明你是双击 `index.html` 打开的，请改用上面的本地服务器方式 |

### 停止服务器

回到那个终端窗口，按 `Ctrl` + `C`。

## 内容原则

1. **每条事实性陈述都带出处。** 正文里的 `[n]` 角标可以点击，跳到页面下方的出处列表（来源名称 + 链接 + 访问日期）。
2. **文化内容不由 AI 生成。** 全部来自公开可溯源资料 —— 非遗名录、官方媒体报道等。
3. **没核实完就明说。** 尚未完成内容核实的菜显示「内容整理中」，**不填任何未经验证的文字**。

## 技术路线

> **原生 HTML + CSS + JavaScript ＋ 单个 JSON 数据文件 ＋ 本地静态服务器**

**不使用框架、不使用后端、不使用数据库。** 原因：本期没有写入功能，数据只有 5 道菜，放在一个 JSON 文件里就够了 —— 部件越少，越不容易出错。

详见 [`TECH_DESIGN.md`](TECH_DESIGN.md)。
